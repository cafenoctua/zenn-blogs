# ブログ執筆ログ記録スキル

今日のブログ執筆セッションの内容を `.claude/session/blog-YYYY-MM-DD.md` に保存する。

## 手順

### Step 1: 日付を取得する

```bash
date +%Y-%m-%d
```

### Step 2: セッションを振り返る

会話履歴全体を確認し、以下を整理する：

1. **執筆した記事** — タイトルとファイルパス
2. **記事の構成** — 主要セクションとキーメッセージ
3. **編集の経緯** — PRコメントへの対応・修正内容
4. **次回やること** — 残タスク・改善点

### Step 3: 保存先ディレクトリを確認する

```bash
ls .claude/session/ 2>/dev/null || mkdir -p .claude/session
```

同日のファイル（`blog-YYYY-MM-DD.md`）が既存の場合は追記か上書きかを確認する。

### Step 4: ファイル内容をユーザーに提示して承認を得る

ファイルパス: `.claude/session/blog-YYYY-MM-DD.md`

出力フォーマット：

```markdown
# ブログ執筆ログ: YYYY-MM-DD

## 執筆した記事
- タイトル: 記事タイトル
- ファイル: articles/<hash>.md
- PR: #N

## 記事の構成・キーメッセージ
- 主要セクション名1: 概要
- 主要セクション名2: 概要

## 編集の経緯
- PRコメントへの対応内容など

## 次回やること
- 残タスク・改善点

---
*記録日時: YYYY-MM-DD*
```

### Step 5: 承認後に保存し、完了を報告する

保存したファイルパスと内容の要約をユーザーに伝える。

## 注意事項

- `.claude/session/` は `.gitignore` で除外済みのため、メモは自由に記載してよい
