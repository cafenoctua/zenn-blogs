# 新記事作成スキル

新しい Zenn 技術記事をゼロから作成する。

## 手順

### Step 1: 記事の内容を確認する

ユーザーに以下を確認する（すでに明示されている場合はスキップ）：
- 記事のテーマ・核心メッセージ
- 参照する素材（セッションログ、コード、ドキュメント等）

### Step 2: ブランチを切る

```bash
git checkout -b new/<記事スラッグ>
```

スラッグはタイトルを英語で短縮したもの（例: `new/rust-axum-blog`）。

### Step 3: 記事ファイルを生成する

```bash
make new-arti TITLE="記事タイトル"
```

生成された `articles/<hash>.md` のファイルパスを確認する。

### Step 4: 本文を執筆する

以下の構成で記事を書く：

1. **frontmatter** — title / emoji / type: "tech" / topics / published: false
2. **はじめに** — 課題感・モチベーション（読者を引き込む導入）
3. **本文セクション** — テーマに応じた見出し構成
4. **まとめ** — 得た知見を3点以内に要約

**文体**: です・ます調  
**コードブロック**: 言語指定を必ず付ける（`rust`, `bash`, `yaml` 等）  
**published**: `false` のまま執筆する

### Step 5: 完了を報告する

作成したファイルパスと記事タイトルを伝える。

## 注意事項

- `node_modules/` の変更はコミットしない
- コミット対象は `articles/<hash>.md` のみ
